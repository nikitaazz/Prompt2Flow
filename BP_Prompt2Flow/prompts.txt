Request - build a business process model which describes deployment of the new feature for the existing website. Usually it is developed on a separate git branch. Here are the steps:
1. Once the feature is ready, the developer pushes it to the staging site and sends the client a message with a brief description and verification step list.
2. Having tested the feature, the client:
2a. Confirms everything works as expected.
2b. Asks to make some adjustments.
3. The developer receives the feedback from the client:
3a. Makes changes in case additional modifications are needed and updates the staging site (see #1)
3b. Merges git branch into the main and pushes the new functionality to the production site, removes the git branch, notifies the client about successful deployment.

Business Process: Frying an Egg in a Pan
First, take a frying pan, either non-stick or regular. If it is made of cast iron, add a drop of oil. If it does not have a non-stick coating, use plenty of oil. Put the pan on the stove and wait until it heats up. Crack an egg into the pan without dropping the shell in. Add salt and pepper to taste, then cover the pan with a lid. Wait a couple of minutes, turn off the heat, and scrape the egg off the pan.
